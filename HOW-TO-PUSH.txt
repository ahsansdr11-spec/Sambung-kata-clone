=== LANGKAH DI TERMUX ===

1) Masuk ke folder repo kamu:
   cd ~/nama-repo-kamu

2) WAJIB backup + hapus file lama dulu (jangan skip ini):
   cp -r . ../backup-$(date +%Y%m%d%H%M) 2>/dev/null || true
   rm -rf api assets css data js lib admin.html index.html vercel.json package.json .gitignore *.md *.txt 2>/dev/null || true

3) Unzip file BARU ini (sambung-kata-vercel.zip) di folder yang sama:
   unzip -o /sdcard/Download/sambung-kata-vercel.zip

4) Push (cuma 3 perintah git, gak ribet):
   git add .
   git commit -m "Fix critical app.js bug + contributions + my-stats + bulk import + csv export + activity log"
   git push

=== LANGKAH DI VERCEL (WAJIB, JANGAN SKIP) ===

5) Buka vercel.com -> project kamu -> tab "Deployments"
6) Klik deployment paling atas -> klik tombol "Redeploy"
   (Push doang KE GITHUB TIDAK CUKUP kalau auto-deploy kamu mati / butuh
   konfirmasi manual — pastikan klik Redeploy biar build terbaru jalan)
7) Tunggu sampai status "Ready"

=== HARD REFRESH DI BROWSER ===

8) Buka web kamu, tekan Ctrl + Shift + R (hard refresh, biar gak kena cache lama)
